从零开始学 CSS 动画：让页面活起来

2026 年 7 月 12 日 · 约 8 分钟 · 字数 1900

你有没有过这种体验：一个网站功能都齐了，但就是觉得 「哪里怪怪的」——多半是太「死」了。 动画就是页面的呼吸，而 CSS 动画是所有方案里性价比最高的那个： 不用引库，不用写 JS，几十行声明式代码就够。

三件套：transition、transform、keyframes

90% 的 CSS 动效，靠这三个东西组合就能完成。先记住它们各自的分工：

  • transform：改样子（位移、旋转、缩放），不引起重排，性能好；
  • transition：让变化「平滑过渡」而不是瞬间跳变；
  • @keyframes：定义多段复杂动画，可以循环、可以自动播放。

第一课：会呼吸的按钮

从一个最简单的悬停效果开始。先写一个普通按钮：

.btn {
  background: #FFD02F;
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}
.btn:hover {
  transform: translate(-2px, -2px);
  box-shadow: 6px 6px 0 #141414;
}

奥秘在 transition 那一行：它告诉浏览器 「transform 和 box-shadow 的变化，请花 0.2 秒慢慢来」。 于是悬停时按钮就会「浮」起来，而不是「啪」地跳一下。 你现在看到的这个网站的按钮，用的就是这一招。

第二课：keyframes，让元素自己动

transition 需要一个触发时机（悬停、聚焦……）。 如果想让元素自己动起来，就要用 @keyframes： 

@keyframes spin {
  to { transform: rotate(360deg); }
}
.star {
  animation: spin 26s linear infinite;
}

这段代码的意思是：从当前状态转到 360 度，用 26 秒， 匀速（linear），无限循环（infinite）。 首页右下角那只慢慢转的小鸡 🐤 就是它。

第三课：进场的仪式感

内容滚动到视口时淡入，是提升质感最立竿见影的一招。 CSS 负责状态，JS 只负责「告诉 CSS 何时切换状态」： 

/* CSS：初始藏起来，加了类才出现 */
.reveal {
  opacity: 0;
  transform: translateY(26px);
  transition: 0.7s cubic-bezier(0.2, 0.7, 0.2, 1);
}
.reveal.is-visible {
  opacity: 1;
  transform: none;
}
// JS：用 IntersectionObserver 监听元素进入视口
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (e.isIntersecting) {
      e.target.classList.add('is-visible');
      io.unobserve(e.target); // 只播一次
    }
  });
}, { threshold: 0.12 });
document.querySelectorAll('.reveal').forEach((el) => io.observe(el));

最后一课：体贴一点

有一部分用户（比如前庭功能障碍者）会觉得动画是折磨。 尊重系统的「减少动态效果」设置，是一行动画人的基本修养： 

@media (prefers-reduced-motion: reduce) {
  .marquee-track { animation: none; }
}

课后小练习

  1. 给文章标题加一个悬停时变色的效果（用 transition）；
  2. 做一个加载中图标，用 @keyframes 让它转起来；
  3. 把 cubic-bezier 改成 (0.34, 1.56, 0.64, 1)，感受一下「回弹」。
好的动画不是「动得多」，而是「动得刚刚好」——像好的服务员：你需要他时他在，你不需要时他消失。
